# 올빼미 내전 팀 짜기

칼바람 증강(아수라장) 사용자 설정 내전 기록으로 친구들 실력 점수를 매기고, 두 팀 점수 합이 비슷하게 5대5 팀을 짜주는 도구.

## 준비물
- Windows, Python 3.10 이상 (추가 패키지 없음)
- 롤 클라이언트 실행 + 로그인 (내전 기록이 있는 계정)

## 사용법
1. 롤 클라이언트를 켠다.
2. `팀짜기.bat` 더블클릭 → 점수표가 나오면 오늘 참가자 번호 입력 → 팀 확인 (Enter로 다시 섞기, `q`로 종료)
3. 웹페이지로 만들려면 `python balance.py --page` → `page.html` 생성

클라이언트가 꺼져 있으면 마지막으로 저장한 `data.json` 기록으로 계산한다.

## 웹페이지 (로그인 필요)
`index.html`은 `page.html`을 아이디+비밀번호로 암호화한 페이지다 (PBKDF2-SHA256 60만 회 → AES-256-GCM, 브라우저에서 복호화).
저장소에는 암호문만 올라가고, 아이디·비밀번호와 원본 `page.html`은 올리지 않는다.

```
python balance.py --page          # page.html 새로 만들기
node encrypt.js <아이디> <비밀번호>  # index.html 로 암호화
```

## 데이터 출처
- **내전 기록**: 롤 클라이언트 로컬 API의 내 계정 매치 기록 중 사용자 설정 게임 (10명 전원의 챔피언, 딜, 받은 피해, CC, 회복, 골드, 승패)
- **레벨·솔랭 티어·평소 증강 전적**: 롤 클라이언트 로컬 API (자유랭크 제외, 일반 큐 증강 = queueId 2400)
- **역대 솔랭 최고 티어**: 클라이언트는 지난 시즌까지만 알려줘서 `tiers.txt`에 직접 적는다 (fow.lol / op.gg 시즌 기록 참고)

## 점수 계산
| 항목 | 비중 |
|---|---|
| 내전 활약 | 40% |
| 내전 승률 | 15% |
| 평소 증강 활약 | 20% |
| 평소 증강 승률 | 5% |
| 솔랭 역대 최고 티어 | 20% |

- 챔피언을 딜러 / 브루저 / 탱커 / 서포터로 나누고 역할마다 다른 기록을 본 뒤, **같은 역할끼리 비교**한다.
- 내전 기록은 같은 판 10명 안에서, 평소 증강 기록은 분당 수치로 비교한다.
- 판수가 적은 사람은 활약·승률을 평균 쪽으로 당긴다.
- 각 항목을 12명 안에서 평균 50점으로 맞추고 비중대로 섞는다.
- 팀 나누기는 모든 조합을 계산해, 최적 조합과 3점 이내인 조합 중 랜덤으로 고른다.

비중은 `balance.py` 위쪽의 `WEIGHTS`, `ROLE_WEIGHTS`에서 바꿀 수 있다.

## 참고
롤 클라이언트 로컬 API는 라이엇이 공식 지원하는 기능이 아니다. 이 도구는 기록을 읽기만 한다.
